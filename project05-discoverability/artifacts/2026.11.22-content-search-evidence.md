## Hypotheses and cleared leads

- Malformed YAML recovery is intentional and documented: parser returns the body after the closing delimiter with no value; scanner skips a malformed card rather than aborting. Not findings.
- Empty frontmatter and no-closing-delimiter behavior were separately observed; empty YAML is accepted, an unclosed opener remains body. FA-RS-014 remains a grammar question because standalone delimiter lines are not explicit in the documented contract.
- `IndexMetadata` includes `SCHEMA_VERSION`; omitted schema version is not a finding. `Indexer::clear` commits, so a no-final-batch-commit suspicion is cleared.
- Stopword removal has an original-query fallback when all terms disappear; the probe returned `the-only`. Do not claim all-stopwords become `AllQuery`.
- The captured one-of-three result used a request-level MinimumMatch override ignored by Tantivy; it does not independently test configured percentage semantics. Static code shows the configured percentage is unused (FA-RS-022 proposal).
- Metadata/FTS author/date/chapter/section presence differs: metadata holds author/date while FTS extraction omits those fields, and field availability varies by `ContentType`. The intended shared schema/API contract is not established by this slice; retained as architecture/compatibility question rather than a finding.
- The content helper `normalize_id` divergence from core normalization is a cleared lead: it is referenced only by its own documentation/tests in the inspected source set, with no production caller exchanging IDs with core. It was a provisional lead only, not frozen as FA-RS-034. Metadata returns raw filename stems while FTS normalizes through the core path helper; this same-input API difference is recorded as a compatibility question because a shared identity contract is not established. Different intentional extractor title/type policies are not automatically defects.
- Resolver collision reproductions use controlled synthetic definitions; no claim is made that a live Acme production configuration currently collides.
- Concurrent Tantivy reader-generation snapshot mismatch was not reproduced. Both search and conversion acquire a searcher; exact concurrent-generation semantics remain an explicit unavailable check, not a race finding.
- Public readiness/index missing behavior was read; no missing-index/create readiness defect is asserted. Runtime confirms configured missing Tantivy index selects the Simple fallback and returns its result.
