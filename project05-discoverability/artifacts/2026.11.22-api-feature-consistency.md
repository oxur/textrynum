1. All nine selected manifests explicitly set local default = []; this is not evidence that all transitive dependency defaults are disabled.
2. FTS default exports SimpleSearch, SearchBackend, SearchParams and SearchResults, while Tantivy modules/re-exports are cfg-gated. No claim that default means “only traits/types” survives this source comparison.

5. The graph mock module and root exports both use cfg(any(test, feature = "test-utils")); unit-test and downstream-feature contexts are represented at the declaration level.
6. The MCP http chain forwards to mcp-core/http, which enables the RMCP HTTP feature and optional axum; public HTTP exports and server methods have matching cfg(feature = "http") declarations.
7. The CLI vector-fastembed feature activates optional fabryk-vector with that dependency’s vector-fastembed feature selected, and cfg gates cover the command API and dispatch.
8. FTS and graph name overrides use slot-key maps. The README/source default mismatch does not prove customization is absent or establish names used by any external application.
9. rkyv_cache publicly exposes content and directory hashing helpers. This entrypoint inventory does not assess cache correctness, performance or whether a separate caching feature is desirable.
